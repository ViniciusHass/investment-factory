## Objetivo

Criar a fundação React + TypeScript + Vite no frontend, com scripts e testes básicos executáveis. Este card não implementa telas financeiras, chamadas FastAPI, autenticação, dados simulados de carteira ou descoberta de ativos. Seu contrato externo é apenas o conjunto de comandos de desenvolvimento e CI; contratos HTTP ficam em cards posteriores.

## Dependências antes de READY

- O proprietário aceitou este card e seus comandos de teste em 2026-11-06.
- `develop` e `main` estão protegidas; a implementação usa branch e worktree próprios saindo de `develop`.
- O workflow `Frontend CI / foundation` foi integrado em `develop`. A branch de F01 deve executá-lo. Com o primeiro teste significativo, F01 reativa `npm run test -- --run` e demonstra que uma falha interrompe o PR, sem bypass nem merge automático.

## Critérios de aceite

1. `npm ci` instala a partir do lockfile; `npm run dev` inicia o app local com React e TypeScript estrito.
2. `npm run lint`, `npm run typecheck`, `npm run test -- --run` e `npm run build` passam localmente e no GitHub Actions.
3. A tela inicial usa apenas conteúdo de infraestrutura; não inventa valores, ativos ou desempenho financeiro.
4. O README explica pré-requisitos, scripts, estrutura de pastas, fluxo de uma requisição futura e como adicionar uma feature/tradução.
5. Nenhuma chave de provedor financeiro é incluída no browser, bundle ou repositório.
